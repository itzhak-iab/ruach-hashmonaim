הגדרת Google Analytics

כדי לראות נתוני ביקורים באתר, צריך להגדיר חיבור ל-Google Analytics.

הגדרה חד-פעמית (5 דקות):
1. היכנסו ל-Google Cloud Console
2. צרו פרויקט חדש (או בחרו קיים)
3. הפעילו את "Google Analytics Data API" (לינק ישיר)
4. בתפריט Credentials → Create Credentials → OAuth Client ID
5. סוג: Web Application, הוסיפו את כתובת האתר ב-Authorized JavaScript origins
6. העתיקו את ה-Client ID

נמצא ב-Admin → Property Settings ב-Google Analytics
